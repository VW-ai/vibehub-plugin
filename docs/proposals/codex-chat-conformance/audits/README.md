# Independent specialized audit packets

Every reviewer must record reviewer identity, exact audited commit, scope, sources,
license/maintenance/dependency/security facts, findings by severity and a concrete
recommendation. Review the current implementation and the accepted baseline; do not
recreate the original inventory or copy proprietary Codex Desktop code or assets.

## Message and rich content

Inspect `app.js` Markdown/media/citation/quote rendering, `chat-model.mjs`, both Chat
fixtures, the conformance matrix and the accepted renderer contract. Compare only
the relevant primitives in the already accepted maintained candidates.

## Execution, tools and approvals

Inspect the reducer event coverage, grouped activity hierarchy, command/diff/tool
bounds, progress, server-request forms, retry/interruption and exact host request
routing. Confirm no UI-inferred Agent lifecycle or VibeHub Task state.

## Composer, navigation and accessibility

Inspect text/attachment/audio/quote composition, Enter/Shift+Enter/Escape, selection
during streaming, overlay and request-form focus, narrow behavior, reduced motion,
labels, keyboard reachability and truthful fixed/unsupported controls.

Reviewers should finish with a prioritized recommendation. The main report may only
claim convergence after all three reports exist and cite the same audited commit.
