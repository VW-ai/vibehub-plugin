# @vw-ai/vibehub-core

The local-first VibeHub runtime shared by the VibeHub CLI and MCP server.

Most users should install [`@vw-ai/vibehub-cli`](https://www.npmjs.com/package/@vw-ai/vibehub-cli)
instead of using this package directly.

Source and documentation: <https://github.com/VW-ai/vibehub-plugin>
