OWNER REVIEW PACK

Codex-first product boundary

Promise

Codex familiarity + VibeHub Tasks

Codex owns Threads, Turns, tools, approvals and execution. VibeHub adds a durable Task Graph, focused Task Workspace, Context, Evidence and independent Outcome.

Current composition
  • Chat is the default landing. Project names only the repository-bound VibeHub Project; chat groups are native Codex Thread Sections, and Recents contains only unsectioned real Codex Threads in this folder.
  • Drag and the Chat-header selector move native group membership. Fork preserves lineage and source group; deleting a group returns member Chats to Recents.
  • Codex history from other folders is counted, never listed. Explicit single-folder Codex Project import writes the .vibehub scaffold uncommitted and hands Room creation to distill.
  • Replay and live events share stable app-server item identity; answers stay primary while tool, diff and delegated work group into quiet Turn disclosures.
  • Inline approvals pause the exact Turn; retry, interruption and completion never become VibeHub Outcome claims.
  • Tasks is a distinct top-level destination; typed Search never relabels a Chat as a Task.
  • The Task Inbox surfaces current Needs You boundaries and repository completion history; Running does not notify.
  • A Task opens a focused Workspace; Start routes the exact host handoff into one Codex Thread.
  • Finalized assistant messages and selections offer Create Task, Attach to Task and Remember. Each confirms into one host action that writes one Ticket or Context document uncommitted with exact origin provenance; the Chat is never rewritten, Quote into Task reaches the Agent only inside the host-built packet, and associations never become dependencies.
  • Voice uses ordinary Codex audio input. Realtime conversation stays unavailable until the runtime reports support.
Later, not now

Final desktop wrapper, a Task-update action beyond Attach and Quote into Task, complete visual approval, public packaging and DSH compatibility remain separate Tickets.

Owner decision after review
  1. Does the real Thread now feel calm enough for daily Codex use?
  2. Are grouped execution activities easy to inspect without overpowering the answer?
  3. Does Chat-first still make important Tasks visible at the right moment?
  4. Is Search the simplest bridge across Chat, Task and Context?
  5. Is the bell plus small Needs You Sidebar group enough without becoming a dashboard?
  6. Should Task focus replace the center column or open beside Chat?
  7. Is voice placement familiar and quiet enough?
