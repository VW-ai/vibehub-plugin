# VibeHub Architecture Boundary

VibeHub is Skills plus checked-in Git-native YAML documents. The product ships
no required CLI, MCP server, database, daemon, hook cadence, native runtime,
local web service, background capture, or hidden state. Git and GitHub own
history, concurrency, rollback, and review. Deterministic validation lives in
the bundled dependency-free scripts; semantic judgment lives in Skills.
Anything a Skill introduces beyond this boundary is a defect, not a feature.
