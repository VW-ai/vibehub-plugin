# Ticket proposal validator profile v1

Artifact ID: `vibehub-ticket-validate`

This artifact identifies an independent semantic reviewer for one immutable
VibeHub Ticket graph-change proposal. The reviewer evaluates all six checks in
the frozen proposal-validation policy, cites bounded evidence, preserves
uncertainty, and records a `claimed_unverified` receipt.

The reviewer does not grant authority, authorize application, change Ticket
maturity, select a winning receipt, or mutate the Ticket graph.
